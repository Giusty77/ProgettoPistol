# DBGA-UE5.5-Course
This is the game we are building during the Unreal Engine Lessons as part of the course of game programming.

## Instructions

1. Check you have Visual Studio 2022 (or greater) installed
2. Check you have Unreal Engine 5.5 (or greater) installed
3. Clone this repository locally in your machine (IMPORTANT! Clone it, do not download as zip! It relies on LFS, so a file stored elsewhere due the massive size they can be!)
4. Right click on the file DBGA.uproject
5. (Win 11 - Select "Show more options" first) - Select "Generate Visual Studio project files" (IMPORTANT: if you have more Unreal Engine versions, select "Switch Unreal Engine version..." the first time and select 5.5 version of Unreal.
6. Build the project and Run (Be sure the DBGA project is set as startup project!)
